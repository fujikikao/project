System Architecture

三大技術架構模組

從實體桌面的微觀聲響與肢體動態出發，經由心理學演算法轉譯，最終以光影無縫回歸實體紙面。

MODULE 01 / SENSING

多模態筆觸感知

  • 聽覺感知：高靈敏度接觸式麥克風（Contact Mic）貼附桌面，收錄筆尖摩擦紙張的高頻聲波（10kHz–20kHz），忠實反映紙張纖維質地。
  • 動態感知：結合深度攝影機（Intel RealSense）追蹤手部骨架，或以數位繪圖板擷取精確的壓力（Pressure）與傾斜角（Tilt）。
MODULE 02 / PROCESSING

情感運算與生成

  • 生成核心：結合 TouchDesigner 與 Python 建立即時視覺與聲響運算引擎（本網頁以 HTML5 Canvas 與 Tone.js 實作互動模擬）。
  • 演算法邏輯：依據 Mueller et al. (2018) 身心理論，將「高壓／快速」映射為銳利幾何形態；「輕柔／慢速」映射為流體仿生形態。
MODULE 03 / OUTPUT

虛實疊加反饋

  • 精準光雕投影：利用短焦投影機（Short-throw Projector）進行桌面 Projection Mapping，避免人體遮擋光線。
  • 紙上長出動畫：數位影像無縫疊加於實體紙張上，打破螢幕隔閡，創造筆墨與數位光影共生的魔幻錯覺。
